## 📖 Design Description

### 4-Bit Carry Select Adder

The 4-bit Carry Select Adder performs binary addition of two 4-bit inputs along with an input carry.

The design generates the sum for both possible carry inputs, `0` and `1`, and selects the required result using the actual input carry.

### Verification Strategy

The verification testbench applies different combinations of:

- 4-bit input `A`
- 4-bit input `B`
- Input carry `cin`

The resulting 4-bit sum `S` and output carry `cout` are observed during simulation.

## 🔄 Verification Flow

1. **Simulation:** Simulate the 4-bit Carry Select Adder using the Verilog testbench.
2. **Logic Diagram:** Analyze the logic structure of the Carry Select Adder.
3. **Schematic:** Generate and analyze the Vivado schematic.
4. **I/O Planning:** Assign the input signals to the FPGA slide switches and output signals to the LEDs.
5. **Pin Assignment:** Assign the required FPGA package pins according to the EDGE Artix-7 board.
6. **XDC File:** Save the assigned I/O constraints in the Vivado XDC file and verify that the assignments are saved correctly.
7. **Synthesis:** Run synthesis in Vivado.
8. **Implementation:** Run implementation after successful synthesis.
9. **Bitstream:** Generate the FPGA bitstream.
10. **FPGA Programming:** Program the generated bitstream onto the EDGE Artix-7 FPGA board.
11. **Hardware Verification:** Verify the adder operation using the assigned switches and LEDs.

### I/O Pin Assignment

For 4-bit switch and LED operations, the pins are assigned from right to left.

The rightmost/top-side pin is considered the **LSB**, while the fourth/bottom-side pin is considered the **MSB**.

| Bit | Position |
| :--- | :--- |
| `bit[0]` | Rightmost / first pin |
| `bit[1]` | Second pin |
| `bit[2]` | Third pin |
| `bit[3]` | Fourth pin / MSB |

For the shown EDGE Artix-7 switch arrangement:

| Switch | Bit |
| :--- | :--- |
| `L5` | `bit[0]` |
| `L4` | `bit[1]` |
| `M4` | `bit[2]` |
| `M2` | `bit[3]` |

The same right-to-left arrangement is followed for 4-bit LED outputs.

### Hardware Verification

The input values applied through the FPGA board are:

| Input | Value |
| :--- | :--- |
| `A` | `0011` |
| `B` | `0101` |
| `cin` | `1` |

The addition is:

```text
  0011
+ 0101
+    1
------
  1001
```

Therefore, the output is:

```text
S = 1001
cout = 0
```

The output `1001` is displayed on the LEDs as shown in the FPGA board figure.
